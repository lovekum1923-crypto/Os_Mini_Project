⚙️ Select & Configure C Scheduling Algorithm

All scheduling logic executes natively inside scheduler.c compiled to WebAssembly.

1. First Come First Serve (FCFS)

Non-Preemptive

Dispatches jobs strictly in order of arrival time. Simple and fair in arrival order, though long CPU bursts can delay shorter waiting jobs (convoy effect).

2. Shortest Job First (SJF)

Non-Preemptive

Selects the ready job with the smallest CPU burst time. Provably minimizes average waiting time for non-preemptive workloads.

3. Priority Scheduling

Non-Preemptive

Executes the ready job with the highest priority rank. Convention: Lower priority integer indicates higher urgency (Priority 1 executes before Priority 5).

4. Round Robin (RR)

Preemptive

Cycles through ready jobs in a FIFO queue, granting each job up to one Time Quantum per turn. Ideal for interactive responsiveness.

📘 About Smart Job Scheduling System

This application demonstrates an authentic hybrid web architecture combining a responsive HTML5 / CSS3 / JavaScript user interface with a high-performance C language scheduling engine compiled to WebAssembly (WASM) via Emscripten.

🏗️ Architecture & Data Flow

  • Frontend (index.html, style.css, script.js): Manages job inputs, validation, linear WASM memory allocation, interactive Gantt visualization, and Chart.js benchmarking.
  • C Engine (scheduler.c): Receives raw job structs via WebAssembly heap pointers, executes FCFS, SJF, Priority, or Round Robin, and writes Gantt slices and performance metrics back to shared memory.

📐 Mathematical Formulas Used

  • Turnaround Time: Completion Time − Arrival Time
  • Waiting Time: Turnaround Time − Burst Time
  • Response Time: First Start Time − Arrival Time
  • CPU Utilization: (Total CPU Busy Time / Total Elapsed Time) × 100
